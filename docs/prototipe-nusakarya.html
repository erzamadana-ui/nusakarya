NUSAKARYA — Operational Control & Supervision Tools

Aplikasi kontrol operasional multi-tenant untuk kontraktor Fiber Optic dan penyedia Manage Service — mitra Telkom Akses. Menyatukan unit Human Resource, Commerce, Procurement, Finance, Operations, dan Design & Deployment dalam satu sistem, dengan tampilan yang menyesuaikan fungsi tiap jabatan.

Web Panel Admin

Panel kerja utama berbasis desktop untuk seluruh unit — data karyawan, procurement, inventory, tiket, hingga proyek deployment. Sidebar tergroup per unit, tabel data-heavy, alur approval berjenjang.

Dashboard Report per Unit

Ringkasan eksekutif untuk tiap unit (Operations, Finance, Deployment, dst) — KPI besar, tren, dan grafik siap dibaca dalam rapat, diakses oleh manajer dan direksi.

Mobile Apps Teknisi

Aplikasi lapangan untuk teknisi — absensi, daftar tugas, checklist work order dengan foto evidence bergeotag, hingga tanda tangan BAST digital pelanggan.

Design System

Bahasa visual bernama Ocean Teal — identitas independen NUSAKARYA (tidak memakai merah-putih Telkom), dipasangkan dengan aksen amber untuk aksi penting.
