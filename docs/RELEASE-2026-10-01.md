## Deploy dan rollback
- GitHub Pages menjalankan build web/admin dan teknisi dengan npm ci, menyusun landing/root + /app + /teknisi, lalu actions/deploy-pages.
- Periksa SHA pada `/release.json` dan hasil job deploy, kemudian uji halaman + form live.
- Bila shell/layout gagal: rollback source perubahan frontend lewat Git revert commit rilis dan tunggu deploy SHA revert. Pertahankan migration containment dan perbaikan security; jangan membuka kembali public RPC atau auto-confirm signup lama.
- Bila provider belum berfungsi: tetap gunakan email. Jangan mengklaim Google/SMS aktif berdasarkan tombol saja; buktikan E2E dengan akun berwenang.
- Jangan buka karantina sebelum scope akses, rotasi akun terkait, retensi data dan review privasi ditutup. Hanya platform admin/service yang dapat mengubah flag.
